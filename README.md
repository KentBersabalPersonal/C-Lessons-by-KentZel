# C Lessons by KentZel

Hey! This repository is where I'm documenting my journey learning C — one concept at a time. Each file focuses on a single topic, with simple, easy-to-follow code so I (and anyone else learning) can look back and understand exactly what's going on.

If you're also just starting out with C, feel free to browse around, learn alongside me, or fork this repo for your own practice!

## What I've Learned So Far

### 🔤 The Basics
- `01-Hello-World.c` – My very first C program
- `02-Variables-and-Data-Types.c` – Storing and labeling data
- `03-Format-Specifiers.c` – Telling printf/scanf how to read and display each data type
- `04-Input.c` – Getting input from the user
- `05-operators.c` – Math, comparison, and logical operators

### 🔀 Control Flow
- `06-Conditional-Statements.c` – Making decisions with if/else
- `07-Switch.c` – Switch statements as an alternative to if/else

### 🔁 Loops
- `08-For-Loops.c` – Repeating code a set number of times
- `09-While-Loops.c` – Repeating code while a condition is true
- `10-Do-While-Loops.c` – Like a while loop, but runs at least once

### 🧩 Data Structures
- `11-Arrays.c` – Storing multiple values in one place

### ⚙️ Functions
- `12-Functions-Prototype.c` – Reusable blocks of code, declared before they're defined
- `13-Void-Functions.c` – Functions that perform an action but return nothing

### 🏗️ Structs & Pointers
- `14-Structs.c` – Grouping related data together
- `15-Pointers.c` – Understanding memory addresses (the scary but important stuff!)

## ▶️ How to Run These Files

You'll need a C compiler like **VS Code**.

Use VS Code for a beginner-friendly compiler :3
